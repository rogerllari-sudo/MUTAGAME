# MUTAGAME

**An interactive genetics education game developed by the Barcelona-UB iGEM 2026 team.**

MUTAGAME is an educational videogame designed to help students understand how DNA mutations can influence proteins, biological functions and phenotypes.

Players experiment with different mutagenic agents, modify five DNA fragments and observe the consequences of their decisions in a simulated biological system.

## About the game

MUTAGAME was developed using Godot 4.6 as part of our iGEM Education initiative. It aims to make abstract molecular biology concepts more accessible through active experimentation and visual feedback.

The game includes:

- Five DNA fragments with different biological functions.
- Four mutagenic agents: UV radiation, ionizing radiation, intercalating agents and viruses.
- Visual representations of DNA, RNA, protein synthesis and phenotypic outcomes.
- Biological feedback and a final diagnosis.
- Colour-vision accessibility improvements, including redundant text and visual indicators.

## How to open the project

1. Install Godot Engine 4.6 or a compatible version.
2. Download or clone this repository.
3. Open Godot Project Manager.
4. Select **Import** and locate the `project.godot` file.
5. Allow Godot to import the project resources.
6. Run the project using F6 for the current scene or F5 for the main scene.
